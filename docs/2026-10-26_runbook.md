# grassfed.food: Runbook

**Updated:** October 26, 2026

## What runs on its own

| Agent | Schedule (Pacific) | Job | Instructions |
|---|---|---|---|
| Scout | Daily, 1:40 am | Finds 10 to 15 new farm candidates, working the state priority list and `ops/leads.md` | `ops/agents/scout.md` |
| Verifier | Daily, 3:10 am | Publishes or rejects candidates, rechecks held listings and listings older than 90 days, resolves organic near-matches | `ops/agents/verifier.md` |
| Writer | Mon, Wed, Fri, 5:15 am | Drafts the next guide in `ops/editorial-queue.md` | `ops/agents/writer.md` |
| Compliance | Daily, 7:20 am | Fact-checks drafts against their sources, then publishes or returns them | `ops/agents/compliance.md` |
| Builder | Tue and Thu, 9:45 pm | Builds the next item in `ops/site-backlog.md` | `ops/agents/builder.md` |
| Monitor | Mon, 6:35 am | Weekly health and traffic report in `ops/reports/`, push notification to Harry | `ops/agents/monitor.md` |
| Organic data refresh | 3rd of each month (GitHub Actions) | Downloads USDA's Organic Integrity snapshot and matches farms | `.github/workflows/organic-data.yml` |
| Validate and deploy | Every push to main, plus daily (GitHub Actions) | Blocks anything that fails `npm run validate`, then publishes the site | `.github/workflows/deploy.yml` |

Every agent run appends a line to `ops/run-log.md`. Every review decision is in `ops/compliance-log.md`.

## Where to look

- **Is it working?** Monday's Monitor report in `ops/reports/`, and the run log.
- **What's on the site?** grassfed.food, built from `data/farms/` and `src/content/articles/`.
- **What's waiting?** `ops/editorial-queue.md`, `ops/site-backlog.md`, `ops/leads.md`, `ops/organic-review.md`, and farms with `"listing_status": "unpublished"` (each has a note).

| When | Task |
|---|---|
| Monthly | Enter last month's sessions, pageviews and share of US/UK/CA/AU/NZ traffic from Google Analytics into `ops/traffic.md`, so the Monitor can track ad-network thresholds |
| When the Monitor says traffic qualifies | Apply to Journey by Mediavine or Raptive |
| As needed | Review farms held with `unpublished` status if an agent can't resolve them |

## Pausing or changing an agent

- **Pause or resume:** in Claude, open the scheduled tasks list and toggle the task.
- **Change what an agent does:** edit its file in `ops/agents/`. The next run picks it up.
- **Undo a bad change:** every change is a git commit; revert it on GitHub and the site redeploys.

## Known limits

- Agent sessions can't reach USDA's Organic Integrity site directly; the monthly GitHub workflow handles it.
- Web search and page-fetch limits per session cap how many farms each run can verify.
- Some farm sites block automated reading; those wait in `ops/leads.md` for a later run.
- Guide photos are hosted by Unsplash and couldn't be previewed from the build environment.
